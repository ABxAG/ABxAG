FAQ

Common Questions

What's new in the latest version?

v1.1.16 adds a floating HUD overlay: nine clickable widgets plus a live mirror of your 3D character, toggled with Ctrl+Alt+O. Updates stay fast with differential downloads.

Is ABxAG free to use?

Yes. Download any build for free and bring your own free Gemini API key from Google AI Studio. No subscription, no account.

Do I need an account to use ABxAG?

No signup. Your key is stored encrypted on your own PC (Windows DPAPI) and never sent anywhere except Google's API.

Setup or Portable — which one?

Setup installs ABxAG with fast differential auto-updates. Portable runs from a single file with a guided update wizard — take it anywhere.

Which platforms are supported?

Windows 10/11 (Setup + Portable) is fully supported. Linux has an experimental AppImage without PC control. macOS is planned, not available yet.

Where can I get support?

Open an issue on GitHub or browse all releases — every version installs over any other.
